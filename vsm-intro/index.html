VSM data analysis

These notebooks support the analysis of data generated during experiments conducted on a vibrating sample magnetometer (VSM). The coercivity spectra unmixing notebooks can also be applied to data from IRM acquisition or AF demagnetization experiments conducted on other magnetometers.

  • Hysteresis Loop Analysis This notebook processes raw hysteresis loop data following the protocols of Jackson and Solheid, 2010. Summary hysteresis parameters are calculated from a collection of loops.

  • Hysteresis Loop Analysis (detailed work through) This notebook provides a step-by-step walk through of the processing of hysteresis loops. Each processing step is illustrated and described. This walk through can enable more granular data processing and illustrates the decision tree that is automatically implemented in the hysteresis loop analysis notebook.

  • Back Field Processing This notebook analyses backfield data in order to obtain coercivity of remanence (Bcr_{cr}cr​) values.

  • Back Field Coercivity Spectra Unmixing This notebook implements coercivity spectra unmixing, including the MaxUnmix workflow with interactive initial parameter choices, direct curve fitting as an alternative approach, model selection, and bootstrap uncertainty estimation.

References¶
  1. Jackson, M., & Solheid, P. (2010). On the quantitative analysis and evaluation of magnetic hysteresis data. Geochemistry, Geophysics, Geosystems, 11(4). 10.1029/2009gc002932
  2. Maxbauer, D. P., Feinberg, J. M., & Fox, D. L. (2016). MAX UnMix: A web application for unmixing magnetic coercivity distributions. Computers & Geosciences, 95, 140–145. 10.1016/j.cageo.2016.07.009
