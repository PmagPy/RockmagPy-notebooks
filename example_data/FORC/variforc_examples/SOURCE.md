# VARIFORC example measurements

These FORC measurement files are redistributed from the example datasets that
accompany the VARIFORC package, with thanks to Ramon Egli.

- `magnetofossil_S0_a.txt` — magnetofossil-bearing pelagic carbonate, Eastern
  Equatorial Pacific, ODP Leg 138 Site 848, untreated (pre-CBD). One of six
  repeat measurement sets. 450 reversal curves at 0.5 mT on an AGM.
  Original file name `S0_a.txt`.
- `magnetotactic_MV1.txt` — cultured magnetotactic bacteria (*vibrio* MV-1),
  a near-rectangular hysteresis loop. Original file name `MV-1.txt`.

**Source.** Egli, R. (2013). VARIFORC: An optimized protocol for calculating
non-regular first-order reversal curve (FORC) diagrams. *Global and Planetary
Change*, 110, 302–320. https://doi.org/10.1016/j.gloplacha.2013.08.003

Example data distributed with the VARIFORC package,

Egli et al. (2010) for the central-ridge analysis of such samples.
